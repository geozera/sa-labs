## About

Welcome!

This repository is a code snippet storage containing implementations of solutions to several problems faced on high scale systems.

The goal of each implementation is to describe the problem that it is aiming at, some approaches to that problem, a concrete solution and a visual benchmark proving its correctness.

The main reason for this repo is for me to document the progress and chain of thought acquired on my software development journey, but it can also be used as a go-to for explaining a problem->solution strategy to someone, or a place for discussions over implementation.

I'll do my best to keep each solution documented, separated and easily reproducible via containerization solutions like Docker or Podman, but will also leave screenshots and benchmarks available. This way you can just trust the results and check the code, or run them yourself and see it in practice.
